# Technical Steering Committee

This repository is use for Organization-wise issues and for interacting
with the Technical Steering Committee (TSC) of the Mainframe Software
Hub for Linux.

See the [Mainframe Software Hub for Linux
Documentation](https://github.com/linuxonzapps/docs) for more project
documentation.

## Issues

You may create Issues in this repository that concern the whole
Organization. Project-specific issues should be raised within the
projects in this Organization directly.

## Calendar & Meetings

Meetings are held on the fourth Thursday of the month at 15:30 UTC.

See the public calendar for the project for details on how to join, or if there
are any changes to this schedule: [LFX Meetings: Mainframe Software Hub for
Linux](https://zoom-lfx.platform.linuxfoundation.org/meetings/mainframe-software-hub-for-linux)

Members of the TSC and the broader community attend these meetings.
